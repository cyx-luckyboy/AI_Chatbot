# 小猪 AI 助手 — 使用说明与代码导读

本文档面向：**日常怎么用软件**，以及：**代码大致分几块、各负责什么**。详细实现仍以源码为准。

---

## 一、软件操作说明

### 1.1 如何运行

| 场景 | 做法 |
|------|------|
| **开发调试** | 在项目根目录执行 `npm start`（Electron + Vite 热更新）。 |
| **绿色包** | 执行 `npm run package` 或 `npm run make:zip`，在 `out` 目录找到 Windows 文件夹或 zip，解压后运行其中的 exe。 |
| **安装包** | 执行 `npm run make`，使用生成的安装程序（Squirrel）。若安装失败，可优先用 zip 包；包名 `name` 需为英文（当前为 `pig-ai-assistant`）以利于安装器。 |

在浏览器里直接打开 Vite 地址时，**没有真实 Electron 能力**，界面能开但无法真正发起对话（由 `browserElectronShim.ts` 提供占位 API）。

### 1.2 主界面布局

- **左侧**：会话列表；底部 **「新建聊天」**、**「设置」**。
- **右侧**：当前页内容（首页 / 某会话 / 设置）；顶栏有 **「刷新」**（重载渲染进程）。

### 1.3 新建对话与发消息

1. 点 **「新建聊天」** 进入首页，选择 **厂商与模型**（需先在设置里配置对应 Key）。
2. 在输入框输入文字，点 **发送** 或 **Enter**（**Shift+Enter** 换行）。
3. 回复以流式形式出现在对话区；出错时会有错误提示内容。

### 1.4 附件与图片

- 输入框旁 **「+」** 可添加 **文件或图片**（有数量与大小限制，以界面为准）。
- 发送前附件会保存到本机应用数据目录（或浏览器预览环境下暂存为 **data URL**），主进程按路径 / 二进制内容读取后再拼进发给模型的上下文。

**各类型大致行为（主进程 `helper.ts` 的 `convertMessages`）：**

| 类型 | 处理方式 |
|------|----------|
| 常见纯文本后缀（如 `.txt`、`.md`、`.json`） | 按 UTF-8 读入正文（过长会截断）。 |
| **PDF** | 使用 **pdf-parse（v1，走 `lib/pdf-parse.js` 入口）** 抽取纯文本；扫描件/图片型 PDF 可能抽不到字；单文件约 **25MB** 上限。 |
| **Word（.docx）** | 使用 **mammoth** 抽取纯文本；**不支持旧版二进制 .doc**（请先在 Office/WPS 中另存为 `.docx`）；加密文档可能失败；单文件约 **25MB** 上限。 |
| **图片** | 读入后以 **base64** 作为 OpenAI 兼容的 `image_url` 传入；**需选用支持视觉/多模态的模型**（如通义 qwen-vl、GPT-4o 等），否则模型可能几乎不返回有效正文。用户消息内会尽量 **先图后文**；仅发图时会自动补一句占位说明。 |
| 其他未识别类型 | 不会内联全文，仅提示用户改传文本或说明需求。 |

**气泡里图片预览（Electron）：** 使用自定义协议 **`safe-file`**。URL 必须为 **`safe-file:///` + `encodeURIComponent(绝对路径)`**（三段斜杠），由主进程解析 `pathname` 后映射到本地文件；请勿在纯浏览器里依赖该协议（请用 `npm start` 跑桌面端）。

**说明：** 大模型 HTTP(S) 请求在 **主进程** 发出，在渲染进程 DevTools 的 **Network** 里往往**看不到**接口请求，属正常现象。

### 1.5 语音输入

- **已配置百度语音 Key**（设置 → 通用）：优先走 **百度短时识别**。流程为：**第一次点麦克风开始录音 → 说话 → 再点一次麦克风结束**，识别结果**追加到输入框**，**不会自动发送**，需自行点发送。
- **未配置百度**且系统支持 **Web Speech**：可 **连续听写、实时上屏**；在国内常因网络无法连上谷歌服务而失败，此时建议在设置中填写百度 Key。
- 麦克风、网络或密钥异常时，输入框下方会出现**提示文案**。

### 1.6 设置（「设置」页）

- **通用**：界面语言、字体大小、**百度语音识别** 的 API Key / Secret Key（仅存本机 `config.json`，勿把密钥提交到公开仓库）。
- **模型**：各厂商的 Key、Base URL 等，按表单项填写后**自动保存**。内置种子厂商包括（具体以界面为准）：**百度千帆**、**阿里灵积**、**DeepSeek**、**Claude**、**Kimi**、**小米 MiMo**、**MiniMax**、**ChatGPT（OpenAI 官方 API）** 等；部分厂商支持在设置中填写国内/国际不同 **Base URL**（详见各厂商占位说明）。

### 1.7 数据存在哪里

- **应用配置**：Electron `userData` 下的 `config.json`（语言、字体、各 Key 等）。
- **对话与消息、厂商列表**：浏览器侧 **IndexedDB**（Dexie，库名见 `db.ts`）。
- **用户图片 / 附件**：`userData` 下 `images`、`attachments` 等目录（由主进程 IPC 写入）。

### 1.8 窗口标题与图标

- 标题栏显示名由 **`src/appMeta.ts`** 中常量与主进程逻辑共同保证。
- 图标使用仓库根目录 **`pig.ico`**；打包配置见 **`forge.config.ts`**。

## 二、代码结构 — 各部分功能

### 2.1 进程划分（Electron）

| 进程 | 目录 / 入口 | 职责摘要 |
|------|----------------|----------|
| **主进程** | `src/main.ts` | 创建窗口、系统菜单、`safe-file` 协议、加载页面；最早执行 `squirrel-startup`。 |
| **预加载** | `src/preload.ts` | 安全桥接：把 IPC 封装成 `window.electronAPI`，类型在 `preload.d.ts`。 |
| **渲染进程** | `src/renderer.ts` → Vue | 全部 UI、路由、Pinia、Dexie 访问（IndexedDB）。 |

主进程与渲染进程通信集中在 **`src/ipc.ts`**（`setupIPC` 在 `main.ts` 里调用）。

---

### 2.2 主进程核心文件

| 文件 | 功能 |
|------|------|
| `src/main.ts` | 窗口（标题、图标）、**`safe-file` 特权协议注册**与 **pathname 解析**、加载 dev/生产页面、DevTools（开发）。 |
| `src/ipc.ts` | `start-chat` 流式对话、`get/update-config`、百度 ASR、复制图片、保存附件、右键菜单等。 |
| `src/menu.ts` | 应用菜单、会话右键菜单（文案随语言配置）。 |
| `src/config.ts` | 读写 `userData/config.json`。 |
| `src/baiduAsrMain.ts` | 百度 OAuth token + 语音识别 HTTP 调用（避免渲染进程 CORS）。 |
| `src/squirrel-startup.ts` | Windows Squirrel 安装生命周期入口处理。 |

---

### 2.3 渲染入口与壳

| 文件 | 功能 |
|------|------|
| `src/renderer.ts` | 引入 `browserElectronShim`、挂载 Vue、Router（Memory）、Pinia、i18n。 |
| `src/App.vue` | 左右分栏布局、会话列表、新建聊天/设置入口、`RouterView`。 |
| `src/browserElectronShim.ts` | 非 Electron 环境模拟 `electronAPI`；附件 `saveUserAttachment` 返回 **data URL** 以便 `<img>` 预览（无法真实调主进程对话）。 |
| `src/appMeta.ts` | 应用显示名常量（与标题栏一致）。 |
| `src/i18n/`、`src/locales/zh.ts`、`en.ts` | 国际化。 |
| `src/rootFontSize.ts` | 根字号（与设置里字体联动）。 |

---

### 2.4 页面（`src/views`）

| 文件 | 功能 |
|------|------|
| `Home.vue` | 新建会话、选模型、首条消息与附件发送流程。 |
| `Conversation.vue` | 单会话：消息列表、输入、流式监听、附件持久化后发 IPC。 |
| `Settings.vue` | 通用设置 + 各厂商模型配置表单。 |

---

### 2.5 数据与状态

| 文件 | 功能 |
|------|------|
| `src/db.ts` | Dexie：表 `providers` / `conversations` / `messages`；`initProviders` 种子数据。 |
| `src/stores/conversation.ts` | 会话列表与 `db` 同步；`fetchConversations` 合并并发请求；新建会话后全量刷新列表，避免与首屏拉取竞态导致会话丢失。 |
| `src/stores/message.ts` | 当前会话消息与 `db` 同步；加载会话时会将异常的 `loading`/`streaming` 助手消息修正为 `finished`；流式更新在会话页侧用 `computed` 判断「是否仍在回复」以避免输入框误禁用。 |
| `src/stores/provider.ts` | 厂商列表。 |
| `src/types.ts` | 会话、消息、配置、聊天载荷等类型定义。 |

---

### 2.6 AI 与消息处理

| 文件 | 功能 |
|------|------|
| `src/providers/createProvider.ts` | 按名称创建具体 Provider。 |
| `src/providers/BaseProvider.ts` | 流式 `chat` 抽象。 |
| `src/providers/OpenAIProvider.ts` 等 | 各厂商 API 实现。 |
| `src/helper.ts` | `convertMessages`：附件/图片/PDF/ **docx** /文本 → OpenAI 兼容或 Claude 所需格式；含 **data URL** 附件路径的读取分支。 |
| `src/ipcSerialize.ts` | IPC 前序列化聊天参数（去掉不可克隆字段等）。 |
| `src/persistUploads.ts` | 将渲染进程附件交给主进程落盘，得到本地路径供模型使用。 |

---

### 2.7 语音相关

| 文件 | 功能 |
|------|------|
| `src/speech/useVoiceInput.ts` | 麦克风开关、百度 / Web Speech 分支、错误状态。 |
| `src/speech/wavEncode.ts` | 录音编码为 16k WAV + Base64（百度用）。 |

---

### 2.8 UI 组件（`src/components`）

| 文件 | 功能 |
|------|------|
| `MessageInput.vue` | 输入、附件、语音按钮、发送。 |
| `MessageList.vue` | 消息列表与展示。 |
| `ConversationList.vue` | 左侧会话列表。 |
| `ProviderSelect.vue` | 厂商与模型选择。 |
| `Button.vue` | 通用按钮。 |

---

### 2.9 构建与配置（仓库根）

| 文件 | 功能 |
|------|------|
| `forge.config.ts` | Electron Forge：图标、extraResource、各 maker。 |
| `package.json` | 脚本、`name` / `productName`、依赖。 |
| `vite.base.config.ts` 等 | Vite 分包构建主进程 / preload / 渲染进程；`bundleIntoElectronMain` 含 **`pdf-parse`、`mammoth`** 等需在主进程打包的依赖。 |
| `.npmrc` | 例如 Electron 镜像，减轻国内下载失败。 |

## 五、近期变更摘要（开发记录）

以下为近期迭代中与用户可见行为相关的主要改动，便于对照版本与排错：

- **厂商接入**：增加 **小米 MiMo**、**MiniMax**、**ChatGPT / OpenAI 官方** 等入口（`db.ts` 种子数据、`providerConfig.ts`、`createProvider.ts`）。
- **附件解析**：PDF 文本抽取、**.docx**（mammoth）、图片多模态内联；**pdf-parse** 固定 **v1.x** 并避免使用包入口文件（防止主进程调试代码读测试路径）；主进程打包依赖见 `vite.base.config.ts`。
- **图片预览与协议**：`safe-file` 使用 **`safe-file:///` + 编码路径**；`app.ready` 前 **`registerSchemesAsPrivileged`**；`MessageList` 对 **data:/blob:** 与本地路径分流。
- **会话与流式**：修复新建会话竞态、多轮对话输入框误禁用、部分 OpenAI 兼容流 **尾随空 chunk** 导致状态回退；流式 IPC 回调 **串行**处理；**OpenAIProvider** 增强 **delta 文本抽取**（兼容多种兼容网关格式）。
- **文案**：含图但回复无效或极短时，界面可提示选用 **视觉/多模态模型**（`locales` + `Conversation.vue`）。
