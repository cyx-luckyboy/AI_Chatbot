# 奶龙音色 TTS（本地服务）

本仓库内路径（monorepo）：

| 路径 | 内容 |
|------|------|
| `vendor/GPT-SoVITS/` | GPT-SoVITS + 奶龙权重 + API |

## 启动 TTS

```powershell
npm run voice:tts
# 或
vendor\GPT-SoVITS\start-nailong-tts.bat
```

默认：`http://127.0.0.1:9880`。也可在 **设置 → 外观 → 旁路服务** 一键启动。

## 和对奶龙对话

1. 设置 → 开启「显示透明桌宠窗」
2. 设置 → 填写「百度语音」API Key / Secret（实时对话用）
3. 桌宠点 **「麦」** 进入**待命**：说 **「奶龙」** / 「嘿奶龙」/ 「你好奶龙」唤醒后开始听指令（也可**点一下奶龙**手动唤醒）
4. 唤醒后正常说话，停顿约 0.8 秒自动识别并回复
5. **打断**：奶龙播放回答时，说「停下」「停止」「闭嘴」「别说了」或再次说「奶龙」可打断
6. 约 45 秒不说话会自动回到待命；再点「麦」结束
7. 或点 **「聊」** 打字发送；对话在主窗口「奶龙」会话

未启动 TTS 或合成失败时桌宠会提示「嗓子哑了」。请先启动旁路 TTS 服务。

本地合成短句通常要 **数秒到十几秒**。分句流水线：先播开头，同时合成后续。

## TTS 日志

- **设置 → 旁路服务**：TTS 进程 stdout/stderr
- **设置 → 桌面宠物 → TTS 日志**：应用内合成/播放耗时（`[petTTS]`）
